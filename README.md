# Terrore a Golasecca · Halloween 2026

Sito statico responsive per l’evento di Halloween della Pro Loco Golasecchese. Pubblicato con GitHub Pages sul dominio personalizzato [terrorea.golasecca.org](https://terrorea.golasecca.org/).

## File del sito

- `index.html`: pagina principale, programma, mappa, parcheggio, informazioni e merchandise.
- `media/halloween 2026/`: immagini, versioni di lavoro e locandina PDF dell'evento. Le immagini usate dalla pagina includono `halloween-golasecca-bg.jpg`, `parcheggio-halloween-bg-v2.jpg`, `aspettando-halloween-laboratorio-2026.jpg` e i tre prodotti merchandise.
- `CNAME`: associa il sito al dominio personalizzato.

Per aggiornare il sito, modifica `index.html` e pubblica immagini e PDF in `media/halloween 2026/`. Nei collegamenti HTML, lo spazio del nome della cartella è scritto come `%20`.

## Visibilità su Google

`index.html` contiene il titolo, la descrizione, l'URL canonico e i dati strutturati dell'evento. `sitemap.xml` elenca la pagina pubblica e `robots.txt` indica a Google dove trovare la sitemap.

Per monitorare l'indicizzazione, verifica `https://terrorea.golasecca.org/` in Google Search Console e invia `https://terrorea.golasecca.org/sitemap.xml`. Quando sarà confermata la via esatta della manifestazione, completa anche l'indirizzo dell'evento nei dati strutturati.
