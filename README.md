# Terrore a Golasecca · Halloween 2026

Sito statico responsive per l’evento di Halloween della Pro Loco Golasecchese. Pubblicato con GitHub Pages sul dominio personalizzato [terrorea.golasecca.org](https://terrorea.golasecca.org/).

## File del sito

- `index.html`: pagina principale, programma, mappa, parcheggio, informazioni e merchandise.
- `halloween-golasecca-bg.jpg`, `parcheggio-halloween-bg-v2.jpg`, `aspettando-halloween-laboratorio-2026.jpg`: immagini usate dalla pagina.
- `merch-felpa-nera.jpg`, `merch-felpa-arancione.jpg`, `merch-maglietta-nera.jpg`: immagini dei prodotti.
- `volantino-laboratori-2026.pdf`: locandina originale con modulo di iscrizione.
- Le immagini `.png` e le varianti JPEG del parcheggio sono conservate come sorgenti e versioni di lavoro.
- `CNAME`: associa il sito al dominio personalizzato.

Per aggiornare il sito, modifica `index.html` e pubblica i file necessari nella root della repository. Le immagini e il PDF devono mantenere i nomi usati nei relativi collegamenti HTML.
